# 스킬트리 가지 배치와 곡선 연결

## 표시 데이터

SkillDataTable의 RequiredSkill을 사용한다. 캐릭터 고유 패시브와 이름이 비어 있는 행은 표시하지 않는다. 코드에 스킬별 좌표 목록을 두지 않는다.

## 가지 배치

- 캐릭터를 화면 중앙에 두고 계열별 가지를 방사형으로 펼친다. 여러 선행 조건을 가진 스킬은 첫 선행 조건의 가지에 배치하되 모든 선행 조건을 연결한다.
- 서로 선행 조건을 공유하는 계열이 이웃하도록 계열 순서를 정한다. 작은 계열에도 최소 각도 영역을 확보하여 시작 스킬끼리 몰리지 않게 한다.
- 하위 가지도 다른 계열과 연결되는 방향을 고려해 순서를 정한다. 불필요한 왕복 우회가 생기지 않도록 관련 슬롯을 모은다.
- 슬롯은 84px이며 프레임 사이에 여유 공간을 확보한다. 전체 경계는 캐릭터를 기준으로 균형을 맞추고 창 크기가 바뀌면 다시 중앙에 맞춘다. 시작 배율은 0.75다.

## 곡선 연결

- 먼저 전용 출입점과 충돌 없는 경로를 계산한다. 이미 사용한 경로를 다른 연결이 공유하거나 가로지르게 하지 않는다.
- 표시에는 격자 꺾임을 그대로 쓰지 않는다. 가능한 연결은 하나의 3차 베지어 곡선으로 잇는다. 장애물을 돌아가야 하는 경우에는 시야가 열린 구간을 곧게 줄인 뒤 완만한 곡선으로 연결한다.
- 곡선 전체를 샘플링하여 다른 슬롯과 연결선에 닿지 않는지 다시 검사한다. 렌더러와 화살표 배치는 같은 경로 데이터를 사용한다.
- 어두운 외곽선·금색/청록 중심선·가는 하이라이트를 사용한다. 화살표는 경로의 중간에 작게 배치하고 슬롯에 붙은 선은 프레임 가장자리에서 끝낸다.
- 선행 관계가 같으면 계산 결과를 재사용한다. 구매 상태 변경은 배치를 바꾸지 않고 선과 화살표 색만 갱신한다.

## 검증

PIE 팝업 테스트에서 슬롯 간격, 모든 선행 조건의 연결 존재, 실제 곡선의 교차·중첩·가짜 갈림길 부재, 급격한 꺾임 부재를 확인한다. 초기 중앙 정렬, 구매 시 선과 화살표 색 일치, 드래그, 길게 눌러 구매 후 입력 복구도 함께 검증한다.

최종 빌드와 검증 결과는 output/ux-pass-20261114-validation.json에 기록한다.
