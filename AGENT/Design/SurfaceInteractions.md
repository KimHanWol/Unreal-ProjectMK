# 지상 시설·장식 기획과 프로토타입

## 이번에 연결하는 시설

| 시설 | 동작 | 기본 조건 |
|---|---|---|
| 광산 엘리베이터 | 지상과 지하 고정 정거장 사이 즉시 왕복 | 32m·72m까지 실제 도달하면 해당 정거장 해금. 미해금 시 공사 중 안내 |
| 철도 공장 | 철도·수동 광산 열차·전자동 열차와 각각의 제작 설계도 판매 | 최대 도달 깊이 48m. 미해금 시 공사 중 안내 |
| 광부의 집 | 주민의 광물 납품 의뢰 수락·완료 | 의뢰별 깊이 조건과 완료 후 대기 시간 |
| 정비공의 집 | 별도 주민 의뢰 진행 | 광부와 진행·대기 상태 분리 |

시설은 현재 128칸 광산의 고정 지상 배치에 맞춘 프로토타입이다. 작은 112칸 미만 테스트 월드에는 생성하지 않는다. 지하 정거장은 미리 생성된 보호 바닥과 출입 공간을 갖추고, 별도 수직 이동 연출 없이 즉시 이동한다. 정식 NPC 캐릭터 아트는 만들지 않고 주택의 주민 상호작용으로 연결한다.

기본 지상 열 오프셋은 광부의 집15, 정비공의 집39, 엘리베이터94, 철도 공장106이다. 오른쪽 큰 돌 지형 위에 운송 시설을 묶어 배치한다. 지상 시설 아래 보호 돌은 한 줄, 원래 솟은 큰 돌 지형의 여러 줄은 유지한다. 깊이·위치·의뢰는 GameSettingDataAsset.TownFacilities에서 조정한다.

주민은 기존 석탄·구리·철 납품 의뢰를 번갈아 제시하고 완료 후 기본180초 동안 쉰다. 기존 재화 보상과 광부의 중심추 유물 보상을 사용한다. 기믹 유물의 획득 보장을 위해 확률 선지급과 별도 완료 횟수 보장을 함께 둔다. 자세한 유물 후보는 [Relics.md](Relics.md)를 따른다.

## 추가 지상 구조물 후보

| 후보 | 목적 | 우선순위 |
|---|---|---|
| 권양기 작업장 | 오른쪽 돌 지형에서 엘리베이터의 케이블·도르래·동력부를 시각적으로 연결 | 높음, 운송 시설과 함께 꾸미기 |
| 광차 차고 | 빈 열차를 보관하고 설치 전 종류를 확인하는 공간 | 중간, 실제 선로와 연결될 때 추가 |
| 광석 선별장 | 종류별 광물을 정리하고 저장 상자에 분배 | 중간, 공통 인벤토리·상자 재사용 |
| 탐사 기록소 | 최대 깊이·찾은 정거장·완료 의뢰·유물 수집 기록 확인 | 높음, 새 진행 정보 표시 |
| 주민 일감 게시판 | 두 주민의 수락 중인 의뢰와 준비 상태를 함께 확인 | 높음, 새 퀘스트 보상을 만들기보다 기존 의뢰 안내 |
| 갱구 정비 쉼터 | 가진 응급 키트·산소 캡슐을 사용하고 비축 점검 | 중간, 무료 무한 회복 여부는 별도 검토 |
| 환기 설비 | 정거장 주변 작은 안전 구역과 광산 분위기 제공 | 낮음, 산소 긴장과 회복 규칙 검토 필요 |
| 지상 화물 승강장 | 상자 장착·분리와 화물 준비를 위한 작업 공간 | 중간, 실제 운송 시스템과 연계 |

장식 후보는 굵은 권양기 케이블·도르래·로프 릴·공구 걸이·철빔 적치대·광석 자루·작업등·마모된 안내판이다. 실제 철도와 혼동되는 독립 장식 철도는 자동 배치하지 않는다. 신규 캐릭터·몬스터 유형을 장식 때문에 만들지 않는다.
