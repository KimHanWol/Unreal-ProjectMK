# 지상 상호작용·장식 후보

상태: 후보 기획. 아래 새 시설·조작은 아직 구현하지 않았다. 기존 상점·설치 작업대·보관 상자는 유지한다. 지상 광산 물체와 고정 돌출 지형 아래에는 드릴·폭탄으로 파괴할 수 없는 보호 돌을 적용했다. 나머지 지면은 기존 흙이다.

## 상호작용 후보

| 후보 | 플레이에서 하는 일 | 기존 시스템과의 연결 | 우선순위 |
|---|---|---|---|
| 광석 운반 광차 | 채굴한 광물을 잠시 내려두는 광산 분위기의 보관 장소 | 실제 10칸 상자 동작을 재사용. 별도 판매·무한 운송 기능은 만들지 않음 | 높음 |
| 작업 기록 게시판 | 달성한 최대 깊이·찾은 확정 지형을 확인 | 기존 깊이·저장 진행 기록을 표시. 새 퀘스트 보상은 별도 기획 | 높음 |
| 비상 정비대 | 갖고 있는 응급 키트·산소 캡슐을 사용하고 비축 상태를 점검 | 기존 소모품 효과와 소비 조건을 재사용. 무료 무한 회복 여부는 별도 결정 | 중간 |
| 갱구 조명 스위치 | 지상 등불을 켜고 끄고, 갱구 쪽 조명 상태를 바꿈 | 연출 상호작용. 자원·진행 보상을 억지로 붙이지 않음 | 중간 |
| 화물 도르래 | 들고 온 물품을 상자에 옮기는 시각 연출 | 우선 장식으로 배치하고 실제 수직 운송은 저장·경로·장애물 규칙 검토 후 확장 | 낮음 |
| 광산 안내 표지 | 조작 또는 현장 기록 한 줄을 짧게 표시 | F 공통 가이드·기존 대사 영역 재사용. 상시 설명 문구로 HUD를 채우지 않음 | 낮음 |

추천 첫 묶음은 광차 보관함과 기록 게시판이다. 이미 있는 시설과 기능을 재사용하면서 광산에 돌아오는 이유를 만들 수 있다. 운반 광차와 보관 상자는 다른 저장 규칙을 만들지 않는다.

## 장식 후보

- 이어지는 짧은 레일, 침목 묶음, 옆으로 세운 예비 레일.
- 도르래·권양기·벽 케이블·감긴 로프. 여러 소품을 한 덩어리로 배치하고 통행 폭을 확보한다.
- 광석 자루, 깨진 바구니, 철제 공구대, 곡괭이·삽 걸이.
- 지면 가장자리의 잔돌·작은 풀 무리, 갱구 주변의 먼지·마모 자국.
- 등불과 작은 지지 목재. 조명은 산소 보상·광물 식별을 가리지 않게 절제한다.

캐릭터·새 몬스터를 생성하지 않는다. 기존 나무·어두운 철·황동 팔레트와 2px/월드 단위 밀도를 유지하며, 장식의 크기에 맞는 원본 해상도를 쓴다. 장식에 상자처럼 오해할 모양을 쓰면 실제 보관 기능을 연결하거나 상호작용 물체와 확실히 다른 실루엣으로 만든다.

## 배치 원칙

고정 지상 높낮이와 어울리게 작은 작업 구역 단위로 배치한다. 시작 지점·상점 동선은 평지와 통행 여유를 유지한다. 시설 아래 보호 돌은 지상에만 적용하고 지하 장식 아래 흙까지 무조건 보호하지 않는다. 지하 유물 교환처는 [Relics.md](Relics.md)의 별도 검토안을 따른다.
