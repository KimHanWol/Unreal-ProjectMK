# 지상 진행·지지대·철도 프로토타입

## 테스트 진입

최신 에디터에서 플레이한 뒤 F1 테스트 UI를 연다. 테스트 버튼은 저장을 보호하는 플레이테스트 세션으로 전환한다.

- **철도 세트**: 테스트 인벤토리를 비우고 철도20·지지대20·수동 열차1·전자동 열차1·상자3을 제공한다.
- **72m 방문**: 가장 깊은 기본 정거장으로 이동한다. 실제 도달 깊이 샘플링으로 승강기와 공장을 해금한다.
- **의뢰 대기 해제**: 두 주민의 테스트 대기 시간을 제거한다.

설치 물품은 퀵슬롯에 넣어 사용한다. F를 짧게 누르면 상호작용, 약0.8초 누르면 설치물을 회수한다. 사용자가 설치한 빈 상자·작업대·지지대·폭약·열차·철도에 공통 회수 규칙을 적용한다. 내용물이 있는 상자는 회수할 수 없다.

## 지지대

상단 들보와 좌우 기둥 사이를 X 보강재로 채우고 바닥 가로대는 두지 않는다. W를 유지하면 기둥을 따라 초당32월드 단위로 올라가고, 기둥 끝에서는 윗면에 선다. 위로 지지대를 추가해 반복해서 쌓고 올라갈 수 있다. W를 놓으면 일반 중력으로 돌아간다. 가로 이동·비행·넉백·메뉴 진입은 등반을 종료한다.

지지대는 드릴 대상이 아니며 윗면만 단방향 바닥 충돌을 갖는다. 폭약의 기존 설치물 파괴 동작은 유지한다. 위에 다른 지지대나 철도가 있으면 그것을 먼저 회수해야 한다. 지지대는 드랍 물품과 캐릭터 뒤에 그린다.

## 철도와 열차

철도는 인접한 한 칸의 평지 또는 대각선 지면/지지대 위에 놓는다. 캐릭터를 막지 않으며 분기·교차·중복을 허용하지 않는다. 순환을 닫는 마지막 구간은 한쪽을 짧게 끊고 끝 마개를 그려 논리적으로 연결하지 않는다. 열차는 그 끝을 넘어가지 않는다. 이 단절 상태는 저장한다.

수동 열차는 몸으로 천천히 밀며 경사에서는 중력으로 구른다. 전자동은 미는 방향으로 구동되고 오르막도 올라가며 선로 끝에서 멈춘다. 열차끼리는 겹치지 않도록 멈춘다. 현재는 전용 선로 좌표를 따르는 이동 프로토타입이며 Chaos 바퀴 물리를 사용하지 않는다.

열차 앞에서 상자 아이템을 사용하면 부착한다. 부착 상자에 F를 누르면 기존 비모달 보관 슬롯이 열리고 드래그로 물품을 옮긴다. 상호작용 대상 우선순위는 부착 상자→열차다. 빈 상자→열차→철도 순으로 회수한다. 연결 선로에 열차가 남아 있으면 해당 선로의 회수를 막는다.

저장에는 선로 ID/양 끝/단절, 열차 ID/선로/위치/속도/구동 방향, 상자 장착 ID와 내용물, 설치 지지대·작업대가 포함된다. 복구 시 선로 위의 일반 재생성 블록을 제거해 저장된 길이 막히지 않게 한다.

## 시설·의뢰·유물

기본 정거장32m·72m, 공장48m 해금과 두 주택 의뢰는 [SurfaceInteractions.md](SurfaceInteractions.md)를 따른다. 공장은 기존 공통 상점 UI로 철도·수동/전자동 열차와 설계도를 판매한다. 퀘스트는 현재 정의된 광물 납품을 사용하며 새로운 몬스터 종류를 가정하지 않는다.

광부의 중심추는 접촉 피해를 유지하면서 몬스터 넉백만 없앤다. 기본5% 의뢰 보상과 같은 주민 의뢰3회 완료 보장을 갖는다. 보유 유물은 중복 없이 저장하고 체력바 위 배지로 표시한다. 다른 유물은 [Relics.md](Relics.md)의 기획·선택 상태를 유지한다.

## 데이터와 프로토타입 범위

- `DA_GameSetting.TownFacilities`: 시설 열 위치, 정거장 깊이, 공장 조건, 의뢰 목록·대기·보상 확률·확정 횟수.
- `ShopRecipeDataTable.CatalogKey=RailFactory`: 공장 물품과 레시피. 일반 보급소와 목록 분리.
- `DA_VisualStyle.TownSprites`: 시설·열차·철도·유물 이미지.
- 기본 고정 지상 배치는 폭112칸 이상에서 생성한다. 승강기 UI는 지상과 첫 두 지하 정거장을 표시한다.
- 전용 곡선 전환 레일 아트, 운행 연출, 선로 아래 지형 파괴 후 붕괴 처리는 추후 폴리싱 대상이다.

검증 코드는 `TownTransportGameplayTest.cpp`, `RailTransportGameplayTest.cpp`, `StructureRecoveryGameplayTest.cpp`에서 실제 입력·상자 이동·저장 복원을 확인한다.
