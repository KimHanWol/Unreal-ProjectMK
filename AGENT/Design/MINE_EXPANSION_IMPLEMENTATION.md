# 벽보 의뢰·벌목·철도 보정

## 테스트 방법과 데이터

- 마을의 기존 벽보는 `QuestBoard` 시설로 생성한다. F로 의뢰를 수락하고 목표 수를 채운 뒤 벽보에서 보상을 받는다. 기존 몬스터 DataTable 행 이름을 사용하며, 현재 기본 의뢰는 DrillCrawler 3마리·75재화다.
- `DA_GameSetting.TownFacilities.HuntQuests`에서 몬스터 행·목표 수·보상·최소 깊이를 수정한다. 처치 수·수락·보상·대기는 저장한다. 임의 Destroy나 월드 정리는 처치에 포함하지 않는다.
- `DA_GameSetting.Forestry`에서 벌목 나무 열과 재성장 시간을 조절한다. 기본 상대 열은14·22·30, 재성장은90초다. 드릴로 줄기·잎을 채굴하며 줄기 아래를 끊으면 기존 붕괴 처리로 위쪽이 떨어진다. 남은 조각이 있으면 재성장을 시작하지 않는다.
- 부분 벌목과 낙하한 조각 위치, 재성장 시각을 저장한다. 나무가 완전히 사라진 뒤 시간이 지나고 뿌리의 지형·성장 공간이 확보되어야 다시 자란다. 플레이어가 성장 공간을 차지하면 비워질 때까지 기다린다.
- BlockDataTable의 TreeTrunk·TreeLeaves는 내구도12·1이다. 줄기는 목재2개를 드랍하며, 목재는 지지대·철도·두 열차의 제작에 들어간다. 나무는 붕괴할 때 자신은 파괴되지만 흙에는 충격을 전달하지 않아 벌목만으로 뿌리 땅이 없어지지 않는다. 이 두 규칙은 `bDropOnCollapse`, `bDamagesTerrainOnImpact`로 구분한다.
- 철도는 한 칸의 좌우 경계를 잇고 주변의 열린 선로 끝을 우선 연결한다. 한 칸 낮은 지형에는 경사가 생기며 반대 방향에서도 대칭으로 연결한다. 기존 분기 금지·순환 단절·수동/자동 운행은 유지한다.
- 지지를 잃은 철도는 철도 아이템이 된다. 해당 구간 위의 수레와 상자도 회수 가능한 드랍으로 바꾸며 상자 내용물은 바닥에 나온다. 단순 회수만 가능한 철도·수레의 머리 위 프롬프트와 UI의 회수 설명 문구는 제거했다. 회수 조작은 공장 상인의 무작위 대사 한 종류에서만 안내한다.
- 몬스터 미끼방은 채굴 가능한 바닥과 아래 낙하 공간을 제공한다. 몬스터 DataTable에 최소 낙하 속도·속도당 피해를 추가했다. 상부 붕괴 공략과 하부 낙하 공략을 모두 사용할 수 있으며 정거장과 방이 겹치지 않도록 승강기 주변을 예약한다.
- 엘리베이터는 암전 후 이동하고 도착 지형의 가시성을 즉시 갱신한 뒤 밝아진다. 이동 중 입력을 막고 마지막에 해제한다.
