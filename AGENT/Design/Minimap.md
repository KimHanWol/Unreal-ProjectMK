# 미니맵

- 우상단에 현재 게임 카메라보다 가로·세로 각각 20% 넓은 주변 지형을 표시한다. 카메라 이동과 화면 비율 변화에 맞춰 범위를 갱신한다. 좌우는 월드 X, 위아래는 월드 -Z이므로 지표가 위에 온다.
- 실제 블록 표시와 동일하게 `bNeedTobeHide`가 켜진 블록을 제외한다. 숨겨진 외곽 충돌 경계인 `Border`는 미니맵에 나오지 않고, 실제로 보이는 암석 `Rock`은 남는다.
- 갈색은 채굴 지형, 회색은 채굴 불가 지형, 녹색은 버팀목 / 완충 젤이 적용된 블록이다.
- 플레이어는 청록색 표식, 상점은 금색 표식으로 표시한다. 하단에 플레이어의 X 좌표와 지표 아래 깊이를 칸 단위로 표시한다.
- `ULevelManagerSubsystem`이 이미 관리하는 블록 목록을 0.2초마다 읽는다. 매 프레임 월드 액터를 검색하거나 별도 카메라로 장면을 렌더링하지 않는다.
- 실제 액터 위치를 사용하므로 채굴·발파로 파괴된 블록은 사라지고 낙하 / 착지 / 설치된 블록도 갱신된다.
- 화면 모서리를 플레이어의 XZ 평면에 역투영해 카메라 범위를 계산하고, 표시 범위 밖 블록은 그리지 않는다. 탐험 안개와 광물 표식은 추가하지 않는다.
- `UMinimapWidget`은 `UMKUserWidget`을 상속한다. 로컬 플레이어 Controller가 생성하고 종료 시 제거한다. 클릭을 가로채지 않는다.
- `BP_PlayerController.MinimapWidgetClass`로 레이아웃 WBP를 교체할 수 있다. 바인딩 이름은 `MapArea`(SizeBox), `PositionText`(TextBlock)이다.
- 크기는 `MinimapSize`, 위치는 `ViewportOffset`, 카메라 대비 범위는 `CameraRangeMultiplier`(기본 1.2), 갱신 주기는 `UpdateInterval`로 조정한다.
- 기존 우상단 코인 표시를 위해 위쪽 여백을 두고, PIE 테스트 패널은 좌상단으로 옮긴다.
