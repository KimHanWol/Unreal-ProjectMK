# 낙하 구조물 기획

## 1. 붕괴 규칙 (현재 구현 기준)

- **지지:** 채굴 가능한 블록 덩어리(4방향 연결)는 채굴 불가 블록(Rock, Border, Shop 등)에 하나라도 닿아 있으면 버틴다.
- **붕괴:** 블록이 부서지면 주변 덩어리를 검사해, 지지를 잃은 덩어리를 통째로 떨어뜨린다. 떨어지기 전에 1초간 흔들린다.
- **낙하:** 세로줄 단위로 떨어지며 같은 줄의 블록이나 캐릭터에 닿으면 멈춘다. 캐릭터에게는 낙하 거리 비례 대미지를 준다.
- **충돌 대미지:** `(속도 - 150) × 0.75` (최대 1200).
  - 떨어진 블록 자신은 100%를 받는다.
  - 부딪힌 채굴 블록과 그 아래로는 `FallingBlockImpactPropagationRatios`(기본 70% / 35% / 15%)만큼 전달한다. 채굴 불가 블록을 만나면 전달이 멈춘다.
  - 부딪힌 블록이 부서지면 떨어지던 줄은 멈추지 않고 뚫고 내려간다.
  - Dirt(100) 기준 목표치: 약 3칸 낙하에 떨어진 블록이 깨지고, 약 4칸에 맞은 블록이 깨지고, 약 9칸에 두 칸 깊이까지 뚫린다.
- **드롭:** 드릴 등으로 캔 블록만 아이템을 드롭한다. **붕괴 충격으로 부서진 블록(떨어지다 깨진 블록, 충격 전파로 깨진 블록)은 드롭하지 않는다.** 버텨서 착지한 블록은 드롭을 그대로 가진다.

## 2. 재미가 생기는 상황

| 재미 | 상황 |
|---|---|
| 위협과 회피 | 머리 위 덩어리를 건드려 떨어지는 순간 피한다 |
| 순서 퍼즐 | 보상이 박힌 덩어리를 떨어뜨리면 보상이 깨진다. 지지대를 끊기 전에 보상부터 캐야 한다 |
| 빠른 길 vs 보상 | 덩어리를 떨어뜨려 부수면 길이 빨리 열리지만 안의 광물은 잃는다 |
| 미끼와 함정 | 광물을 캐는 행동이 곧 천장을 무너뜨리는 조건이 된다 |
| 짧은 낙하 vs 긴 낙하 | 짧게 떨어뜨리면 깨지지 않고 쌓여 발판이 되고 드롭도 남는다. 길게 떨어뜨리면 깨진다 |
| 연쇄 | 위 덩어리가 금 간 아래 블록을 뚫고, 그 아래까지 이어서 무너진다 |

## 3. 구조물 목록 (17종)

배치는 **다양성을 우선한다.** 항상 크고 다이나믹할 필요는 없고, 작은 버전이라도 여러 종류가 나오는 것을 목표로 한다.

- **종류 선택:** 모든 종류를 섞은 순서로 한 번씩 시도한다. 다음 회차부터는 적게 배치된 종류를 먼저 시도한다.
- **크기 축소 재시도:** 한 종류가 실패하면 다른 위치로 `FallingStructurePlacementRetryCount`(기본 40)번까지 다시 시도한다. 재시도할수록 크기·높이·낙하 거리를 100%에서 40%까지 줄인다.
- **자리 없음:** 가장 작은 크기로도 실패한 종류는 이후 회차에서 건너뛰고, 남은 시도를 들어갈 수 있는 종류에 쓴다.

| 구조물 | 모양 | 의도 | 보상 | 사전 대미지 |
|---|---|---|---|---|
| TopHammer (기존) | 위에 매달린 톱니 덩어리 | 위협 | - | - |
| SideOverhang (기존) | 옆벽에 붙은 처마 | 위협 | - | - |
| KeystoneWings (기존) | 가운데 지지대 하나에 좌우 날개 | 끊는 지점 읽기 | - | - |
| TriggerCascade (기존) | 작은 추와 처마 | 연쇄 | - | - |
| Stalactites 종유석 | 천장 Rock 에 1칸 기둥 여러 개 | 끝의 광물은 아래에서 캐면 안전, 윗부분을 끊으면 떨어져 깨지고 잃음 | 기둥 끝 35% | 바닥 윗줄 40~60% |
| OreVault 보물 매달기 | 광물 덩어리를 지지대 하나로 매닮, 아래 6칸 이상 + Rock 바닥 | 줄을 먼저 끊으면 보상이 전부 깨지는 순서 퍼즐 | 덩어리 50% | - |

| RockFunnel 돌 깔때기 | 흙덩이 아래 V 자 Rock 계단, 입구 아래 금 간 바닥과 구덩이 | 바깥 줄은 계단에 차례로 부딪혀 깨지고 가운데만 통과해 바닥을 뚫음 | 흙덩이 20% | 바닥 60~80% |

- **보상 아이템:** `MineableLevelGeneration.StructureRewardItemDataList`에서 가중치로 고른다. 현재 값은 Iron 0.5, Gold 0.3, Emerald 0.15, Diamond 0.05이다. 보상 칸에는 광물 아이콘이 보인다.
- **사전 대미지:** 구조물이 연쇄를 설계하려고 지정한 칸에만 준다. 일반 지형은 온전하게 생성한다. 대미지 플립북으로 금이 보여서 어디가 약한지 읽을 수 있다.
- 보상 아이템과 사전 대미지 모두 지형 시드로 정해지므로, 불러오면 같게 나온다.

## 4. 공통 생성 규칙

- **`FinalizeEnclosedStamp`**
  - 몸통(Body / Support)의 둘레 한 칸을 비워 주변 지형과 분리한다.
  - 몸통 아래로 낙하 공간을 비우고 바닥을 만든다.
  - 바닥은 Rock(깨지기 쉬움) 또는 채굴 블록(충격이 전달되며 쌓임) 중에서 고른다.
- **지표면 보호:** 채굴 영역 맨 윗줄부터 `FallingStructureSurfaceMargin`(기본 4)칸 안에는 구조물을 배치하지 않는다. 스폰 지점과 상점 주변을 온전하게 두기 위해서다.
- **앵커:** 지지는 스탬프가 지정한 Rock 앵커로만 한다. 이후 무작위 Rock 배치와 빈 공간 생성은 예약 칸을 건드리지 않는다.
- **개수:** 채굴 칸 1000개당 `FallingStructuresPerThousandTiles`(기본 3.0)개를 만들고 `FallingStructureCount`(12)를 상한으로 둔다. 특수 구조물은 가끔 나오는 것이 목표다. 현재 맵에서는 4개가 나오고, 맵을 넓히면 넓이에 비례해 늘어난다.
- **로그:** 생성 시 `[LevelGen] Falling structures N/M, per pattern: ...`에 13종의 배치 수를 순서대로 남긴다.

## 5. 이후 확장 후보

- 충격에만 깨지는 단단한 광물, 드릴로만 온전히 얻을 수 있는 깨지기 쉬운 광물처럼 드롭 규칙을 광물마다 다르게 두기
- 맵 확장 후 깊이 구간별로 구조물 종류와 크기 가중치 두기
