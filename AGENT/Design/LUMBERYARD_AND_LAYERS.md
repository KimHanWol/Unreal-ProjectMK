# 벌목장 부지와 배경 배치

## 전용 벌목장

DA_GameSetting.Forestry의 YardStartColumn3·YardEndColumn35는 맵 시작 열에 대한 상대값이다. 이 구간은 기본1칸 높이의 평평한 작업 부지로 생성하고, 오두막은6열·나무는14/22/30열의 화단에서 자란다. 나무와 가로등·작업장 아래에는 한 칸짜리 보호 기반을 둔다. 일반 무작위 장식은 이 부지를 제외한다.

각 화단은 줄기2칸과 연결된 수관15칸으로 구성한다. 모든 잎이 없어지고 줄기를 포함한 조각을 다 치운 뒤 기존90초 재성장이 시작된다. 부분 벌목 상태와 잎의 세부 그림 키를 저장한다. GroundRow도 저장해 부지 높이가 바뀌어도 나무 조각이 땅에서 뜨거나 묻히지 않게 한다. 이전 저장은 기존 고정 지형의 높이를 사용해 한 번 보정하고 잎 그림을 좌표에 맞는 새 영역으로 바꾼다.

예전 자동 배치 길가 상자가 새 부지에 남아 기반을 파내는 사례를 실제 저장 화면에서 확인했다. 자동 장식 ID인 DECH의 지상 상자만 구분하여 빈 상자는 제거 상태로 남기고, 내용물이 있으면 ID·물품을 유지해 벌목장 바깥의 빈 곳으로 옮긴다. 플레이어가 설치한 상자와 매장·열차 상자는 기존 방식으로 복원한다. 바깥 자리가 모두 막혀 있으면 외곽 블록 위에서 떨어질 수 있게 복원해 내용물을 보존한다.

## 가로등과 배경

가로등은 기존 배율1.15의 원본 대신48×112 원본을 배율1로 사용한다. 벌목장에는 화단 사이와 출입 쪽4개를 두며 일반 지상에도 약8칸 간격의 후보에서 주변2칸까지 위치를 조정한다. 건물·큰 장식·상자와 겹치는 후보와 경사 때문에 발이 뜨는 후보는 제외한다.

배경 주택군은7/23/38/49/60/72/83열, 산업 배경은96/107열에 배치한다. 일부를 좌우 반전해 반복을 줄이고 기존 낮은 대비를 유지한다. BackgroundParallaxStrength 기본값은0.18이다. 작은 이동량에서 멈추던 고정 클램프를 제거하여 캐릭터 이동에 연속적으로 역방향 시차가 생긴다. 동일 위치에서는 렌더 액터의 변환을 다시 설정하지 않는다.
