# 유물 기획 초안

상태: 기획 검토용. 유물 기능과 아래 획득 보상은 아직 구현하지 않았다. 현재 구현된 이동·비행·드릴·산소·낙하 블록·버팀목·완충 젤·발파 폭약·귀환 신호탄·작업대·보관 상자와 기존 구조물 패턴을 기준으로 한다. 몬스터의 종류별 능력과 드롭은 아직 기획하지 않았으므로 가정하지 않는다.

## 공통 규칙

- 총 20종 초안: 기믹 12종, 보조 수치 강화 8종. 기믹은 단순 수치 대신 조작·판단·자원 사용·동선을 바꾸는 효과다.
- 획득 즉시 항상 적용한다. 인벤토리와 퀵슬롯을 점유하지 않으며 사망으로 잃지 않는다. 같은 유물의 중복 획득과 중복 강화는 없다.
- 기믹 유물은 확정 배치 지형의 지정 보상 또는 상시 구매 가능한 레시피를 통한 1회 제작으로 제공한다. 필요한 유물 없이도 해당 획득처에 도달하고 재료를 얻을 수 있어야 한다.
- 몬스터 획득처는 몬스터 기획 이후 배정한다. 유물을 준다고 가정해 새 몬스터 종류를 먼저 만들지 않는다.
- 무작위 매장 상자는 확률 보상이므로 필수 기믹 유물의 유일한 획득처로 사용하지 않는다.
- 확정 지형은 위치와 형태 세부가 시드별로 달라도 지정 패턴의 등장은 보장한다. 유물별 깊이·보상 위치는 별도 진행 단계 데이터로 지정할 예정이다. 현재 구조물의 광물 보상에 유물이 적용된 것은 아니다.

## 기믹 유물 12종

수치와 이름은 조정 가능한 초안이다. 확정 지형 보상과 일회 제작의 최종 분배는 진행 속도 검토 후 정한다.

| 유물 | 조작과 효과 | 판단과 제약 | 획득 경로 초안 |
|---|---|---|---|
| 끈끈이 신발 | 벽 방향 입력을 유지하면 잠깐 벽에 붙는다 | 반대 입력으로 해제. 착지 전 연속 재충전 불가. 산소는 정상 소모 | 얕은 구간의 확정 패턴 보상 |
| 드릴 짐벌 | 비행·낙하 중에도 방향 드릴을 쓴다 | 사거리·위력은 기존 값을 사용하고 먼 블록은 채굴하지 않는다 | 상점 레시피, 1회 제작 |
| 드릴 앵커 | 공중에서 맞닿은 벽을 채굴하는 동안 그 표면에 몸을 고정한다 | 드릴 짐벌 보유 필요. 블록이 깨지거나 입력을 놓으면 즉시 떨어진다. 비행 키가 우선한다 | 짐벌 이후 1회 제작 |
| 붕괴 투시경 | 블록을 조준하면 그것을 제거했을 때 떨어질 덩어리를 윤곽으로 예고한다 | 현재 지지 상태를 기준으로 예측. 다른 낙하·폭발이 발생하면 즉시 갱신 | 확정 패턴 보상 |
| 충격 채굴추 | 일정 높이 이상 낙하할 때 아래 드릴을 유지하면 착지 지점 한 칸에 충격 채굴을 가한다 | 옆이나 먼 칸에는 적용하지 않는다. 반동 후 재낙하가 필요하고 연쇄 광역 채굴은 없다 | 확정 낙하 패턴 보상 |
| 낙하 포집망 | 가까운 곳에서 낙하 충격으로 사라진 광물 블록의 보상 한 묶음을 건진다 | 한 붕괴에서 1회만 적용. 직접 채굴한 블록과 발파에는 적용하지 않는다. 일반 채굴이 여전히 가장 안전한 수확 방법 | 확정 패턴 보상 |
| 산소 축전낭 | 산소 보상으로 넘친 양을 작은 예비분으로 비축하고 산소가 부족해지면 자동 방출한다 | 비축 상한과 방출 기준을 둔다. 산소를 스스로 생성하지 않는다 | 1회 제작 |
| 폐쇄 순환기 | 지면에서 이동·채굴·비행 없이 잠깐 쉬면 산소 소모를 일시 정지한다 | 회복 효과는 없고 행동을 시작하면 즉시 소모 재개. 공중과 피격 중에는 사용할 수 없다 | 1회 제작 |
| 발파 조정기 | 폭약을 설치한 뒤 같은 퀵슬롯을 다시 눌러 설치한 폭약을 직접 기폭한다 | 기존 자동 도화선을 수동 기폭으로 전환. 설치와 기폭을 구분해 기폭에 아이템을 추가 소모하지 않는다 | 1회 제작 |
| 회수 릴 | 가까운 설치물에 F를 길게 눌러 버팀목·작업대·빈 상자를 회수한다 | 짧은 F는 기존 상호작용. 내용물 있는 상자는 먼저 비워야 한다. 폭파하면 상자와 내용물이 따로 드롭되는 규칙은 유지 | 1회 제작 |
| 탐사 실타래 | 직접 지나온 길과 마지막 지상 진입 방향을 미니맵에 이어서 표시한다 | 미탐사 공간이나 광물을 새로 공개하지 않는다. 지나온 길이 붕괴로 막혔으면 막힘도 표시한다 | 확정 패턴 보상 |
| 귀환 고정핀 | 상호작용한 작업대나 상자 하나를 귀환 신호탄의 목적지로 지정한다 | 신호탄 소모와 기존 대기 시간을 유지. 목적지가 파괴되면 지상 귀환으로 되돌린다. 지상 귀환을 선택할 수도 있다 | 후반 1회 제작 |

끈끈이 신발은 벽에서 쉬거나 방향을 바꿀 시간을 주고, 드릴 앵커는 채굴 동작 중에만 몸을 지지한다. 기존 비행이 이미 하는 동작을 새 유물의 효과로 중복하지 않는다.

## 보조 강화 유물 8종

모두 확률 보상 후보이며 효과 수치는 초안이다. 매장 상자의 별도 유물 보상 판정, 채굴 보상, 추후 몬스터 드롭 기획에 연결한다. 미구현된 거래품 상자나 특정 몬스터 종류를 획득처로 가정하지 않는다.

| 유물 | 효과 초안 |
|---|---|
| 광부의 안전패 | 최대 체력 +15% |
| 예비 산소통 | 최대 산소 +15% |
| 충격 완충판 | 일반 피격 피해 -8%, 산소 부족 체력 소모 제외 |
| 만물상 증표 | 일반 상점 구매 가격 -8% |
| 감정사의 확대경 | 일반 물품 판매 가격 +10% |
| 선별 체 | 광물 추가 획득 확률 +3%p |
| 초경 드릴팁 | 채굴 위력 +10% |
| 경량 깔창 | 이동 속도 +5% |

할인·판매 보너스는 재구매 차익을 만들지 않게 거래별로 구분하고 무료 물품은 재판매 불가를 유지한다. 유물·확정 보상은 추가 드롭의 대상에서 제외한다.

## HUD와 데이터

- 좌측 체력·산소바 위에 작은 배지를 획득 순서로 표시한다. 기존 공통 슬롯·툴팁 스타일을 재사용하고 인벤토리 슬롯 크기로 키우지 않는다.
- 마우스 호버로 이름·조작·효과·제약을 표시한다. 발동 조건이 있는 배지는 준비·사용 중·재사용 대기 상태를 구분한다.
- DataTable에서 유물 키, 이름, 설명, 아이콘, 기믹/수치 구분, 효과 설정, 획득 규칙, 선행 유물, 일회 제작 여부를 관리할 예정이다.
- 저장은 보유 키와 획득 순서, 필요한 제한적 기믹 상태를 보관한다. 불러올 때 실제 수치를 다시 중복 가산하지 않는다.
