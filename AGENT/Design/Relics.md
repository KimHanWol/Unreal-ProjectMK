# 유물 기획 검토안

상태: 기획 전용. 아래 능력·획득처·유물 상점은 아직 구현하지 않았다. 2026-11-15 사용자 피드백을 반영했다. 현재 이동·비행·접촉 드릴·산소·낙하 블록·발파 폭약·버팀목·완충 젤·귀환 신호탄·작업대·보관 상자를 기준으로 하며, 미정인 몬스터 종류와 드롭은 가정하지 않는다.

## 기본 방향

- 전체 20종 후보: 기믹 12종과 보조 강화 8종. 기믹 12종 중 7종은 사용자 유지 요청을 반영했고 나머지 5종은 검토 후보다.
- 획득하면 항상 소유·적용한다. 인벤토리·퀵슬롯을 차지하지 않고 사망해도 유지한다. 중복 획득과 중복 강화는 없다.
- 기믹 유물은 반드시 얻을 수 있어야 한다. 확정 등장 지형, 상시 구매 가능한 일회 제작 레시피, 확정 배치 교환처를 사용한다. 무작위 매장 상자를 유일한 획득처로 삼지 않는다.
- 획득 순서는 조작을 하나씩 익히게 배치하되 선행 유물 없이 도달·재료 수집이 가능해야 한다. 깊이와 획득처 배분은 다음 검토에서 확정한다.
- 몬스터 보상은 몬스터 기획 후 지정한다. 산소 몬스터·빠른 몬스터 등 아직 없는 유형을 획득 조건으로 쓰지 않는다.

## 유지할 기믹 7종

| 유물 | 구체적인 행동 변화 | 제약과 획득 방향 |
|---|---|---|
| 끈끈이 신발 | 벽 방향 입력을 유지하면 잠깐 벽에 붙어 다음 이동을 준비한다 | 반대 방향 입력·비행으로 해제. 착지 전 무한 재충전 금지. 얕은 확정 지형 보상 후보 |
| 드릴 짐벌 | 공중에서 드릴을 사용할 수 있고, 닿은 블록을 채굴하는 동안 그 자리에 붙는다 | 드릴을 놓거나 대상이 사라지면 해제. 기존 접촉 거리와 채굴 위력 유지. 드릴 앵커는 별도 유물로 만들지 않음. 일회 제작 후보 |
| 충격 채굴추 | 플레이어가 낙하 피해를 입을 때 바로 밑 블록에도 피해를 준다 | 옆·원거리에는 영향 없음. 현재 낙하 블록의 피격과 플레이어 낙하 피해는 구별한다. 플레이어 낙하 피해 규칙은 구현 전에 함께 확정. 확정 지형 보상 후보 |
| 폐쇄 순환기 | 지면에서 이동·채굴·비행 없이 잠깐 쉬면 산소 소모를 멈춘다 | 회복·산소 생성은 하지 않음. 행동·피격·공중 상태가 되면 즉시 소모 재개. 일회 제작 후보 |
| 발파 조정기 | 보유 후 설치한 폭약은 자동 도화선 대신 별도 키로 한꺼번에 기폭한다 | R 키 제안. 설치된 폭약이 있을 때 머리 위 R 가이드, F 상호작용과 겹치면 가이드를 나란히 표시. 기폭에 폭약 추가 소모 없음. 저장·재접속 시 남은 폭약 처리 규칙 필요. 일회 제작 후보 |
| 회수 릴 | 가까운 버팀목·작업대·빈 상자에 F를 길게 눌러 회수한다 | 짧은 F는 기존 상호작용. 물품 있는 상자는 비워야 함. 폭파 시 내용물이 전부 바닥에 나오는 규칙 유지. 일회 제작 후보 |
| 거미줄 장갑 | 공중에서도 설치 가능한 아이템을 사용한다 | 설치물의 빈 칸·겹침 검사는 유지. 지지되지 않은 상자는 설치 직후 실제로 떨어짐. 완충 젤은 바를 블록이 있어야 함. 확정 지형 보상 후보 |

드릴 짐벌은 기존 비행을 조금 강화하는 수치 유물이 아니라 공중 채굴과 채굴 중 고정이라는 새로운 선택을 제공한다. 부착을 계속 유지하는 끈끈이 신발과는 사용 목적이 다르다.

## 추가 기믹 후보 5종

다음은 승인 대기 후보다. 기존 효과와 겹치거나 구현 비용 대비 재미가 약하면 교체한다.

| 후보 | 행동과 선택 | 제약 / 검토점 | 확정 획득 경로 후보 |
|---|---|---|---|
| 발파 집속 렌즈 | 폭약 설치 전에 일반 3×3 발파와 조준 방향으로 길게 파는 집중 발파를 전환 | 블록 파괴 총량·폭약 소모를 비슷하게 유지. 발파 광물 보상 없음, 보호 기반암은 파괴 불가. 전환 조작은 아직 미정 | 일회 제작 |
| 비상 완충 고리 | 낙하 블록이 머리에 부딪히기 직전, 소지한 완충 젤 하나를 자동 사용해 해당 충격을 막음 | 젤이 없으면 발동하지 않음. 피해 흡수만 하고 블록을 관통시키거나 없애지 않음. 준비 상태를 HUD 배지로 표시 | 확정 붕괴 지형 |
| 반동 축전 스프링 | 몬스터 접촉 넉백 직후 짧은 타이밍에 비행 키를 누르면 한 번 더 위로 튀어 탈출 | 시선 유지, 몬스터 반대쪽으로 튕겨 나가는 기존 방향 유지. 산소 소모·재발동 조건 필요. 특정 몬스터 종류를 전제하지 않음 | 일회 제작 |
| 유품 봉인함 | 사망으로 잃는 물품을 사망 지점의 회수용 보관 상자 하나에 남김 | 기존 손실량만 보관하고 코인은 별도 기존 규칙. 돌아가 열어야 하며 상자는 폭파하면 내용물이 흩어짐. 기존 보험 증서가 우선해 중복 보상 방지 | 확정 깊이 지형 |
| 운반 멜빵 | 회수 릴로 내용물이 든 상자를 통째로 들어 짧게 옮기고 다시 설치 | 운반 중 채굴·비행·상자 열기 제한 제안. 폭탄으로 부수면 항상 빈 상자와 내용물이 별도 드롭. 개별 상자 데이터를 운반 상태에 보존하는 확장이 필요해 후순위 | 회수 릴 이후 일회 제작 |

## 제외·통합한 항목

- 드릴 앵커: 드릴 짐벌에 통합.
- 붕괴 투시경, 낙하 포집망, 산소 축전낭, 탐사 실타래, 귀환 고정핀: 사용자 요청으로 제외. 이름만 바꿔 같은 기능을 다시 넣지 않는다.

## 보조 강화 후보 8종

종류 수를 채우는 보조 효과이며 확률 획득으로 제공한다. 수치는 임시값이다. 매장 상자 보상, 채굴 보상, 추후 몬스터 드롭에 배분할 수 있지만 현재 연결하지 않았다.

| 유물 | 효과 초안 |
|---|---|
| 광부의 안전패 | 최대 체력 +15% |
| 예비 산소통 | 최대 산소 +15% |
| 충격 완충판 | 일반 피격 피해 -8%, 산소 부족 피해 제외 |
| 만물상 증표 | 일반 상점 구매 가격 -8% |
| 감정사의 확대경 | 일반 물품 판매 가격 +10% |
| 선별 체 | 광물 추가 획득 확률 +3%p |
| 초경 드릴팁 | 채굴 위력 +10% |
| 경량 깔창 | 이동 속도 +5% |

할인·판매 보너스와 재구매 가격을 함께 계산해 반복 매매 차익을 막는다. 무료 물품과 유물·확정 일회 보상은 추가 드롭 대상에서 제외한다.

## 지하 유물 교환처 — 논의 중

한 지점에서 유물 하나만 취급하는 이상한 상점이다. 구현하지 않고 기획에만 남긴다.

- 사전에 정한 진행 조건과 아이템 지불 조건을 모두 만족하면 한 번 교환한다. 단순 코인 상점과 다른 역할을 준다.
- 기본 검토안은 확정 등장 지형 안에 한 교환처를 배치하고 보상 한 종을 고정하는 것. 매번 상품을 돌리거나 랜덤 재추첨하지 않는다.
- 데이터 후보: ShopId, RelicKey, RequiredItems, MinimumDepth, RequiredProgressFlags, RequiredRelicKeys, bOneTimeExchange. 조건별 안내와 지불 수량은 같은 데이터에서 표시한다.
- 기믹 유물이라면 교환처 등장과 지불 재료 확보 경로가 보장되어야 한다. 그 유물 자체가 없으면 얻을 수 없는 재료를 요구하지 않는다.
- 예시 검토: 특정 확정 지형을 발견한 기록 + 기존 광물 몇 종류를 지불. 실제 유물·수량·깊이는 미정이다.
- 몬스터 처치 조건은 해당 몬스터 기획이 정해진 다음 추가한다.
- 영속 저장: 교환처 ID, 교환 완료 여부, 지급 유물. 인벤토리 공간과 관계없이 유물 소유 목록에 지급하며 지불과 지급을 한 거래로 처리한다.

## HUD·데이터·저장 예정 구조

좌측 체력·산소바 위에 획득 순서대로 작은 배지를 표시한다. 공통 슬롯과 툴팁을 재사용하되 아이템 인벤토리처럼 큰 칸으로 만들지 않는다. 호버에는 이름·조작·효과·제약, 조건부 유물에는 준비·사용 중·재사용 대기를 표시한다.

RelicDataTable에서 키, 이름, 설명, 아이콘, 기믹/강화 구분, 효과 설정, 획득 규칙, 선행 유물, 일회 제작 여부를 관리한다. 저장에는 보유 키·획득 순서·필요한 기믹 상태만 남기고, 불러올 때 GAS 수치를 중복 가산하지 않는다. 구현 시작 전에 기믹 후보와 획득 순서를 확정한다.
