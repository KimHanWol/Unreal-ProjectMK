# 인벤토리·퀵슬롯 UX 수정

2026-11-08 사용자 요청을 기준으로 한다. 이전 패스의 첫 8칸 공유·전체 잠금 표시 규칙을 대체한다.

## 보관과 이동

- 인벤토리는 기본 8칸, 퀵슬롯은 독립된 8칸이다. 획득은 인벤토리로 처리한다. 퀵슬롯은 광물·소지형 보험을 제외한 실제 사용 가능한 아이템만 받는다.
- `UInventoryComponent`가 두 컨테이너와 이동·합치기·교환·소모·판매·필드 드롭을 관리한다. 잘못된 교환은 원본을 보존한다. 자동 정규화로 사용자가 정한 칸 배치를 바꾸지 않는다.
- 저장 버전 2는 두 배열을 각각 저장한다. 이전 저장의 인벤토리는 유지하고 새 퀵슬롯은 빈 상태로 시작한다.
- `UItemSlotWidget`을 HUD·팝업·퀵슬롯에서 재사용한다. 고스트는 원본 아이콘의 화면 크기와 DPI를 반영하고 마우스 중앙을 피벗으로 쓴다.
- HUD 우하단은 열린 인벤토리 칸만 표시한다. 소지품 제목·퀵슬롯 번호·잠금 칸은 넣지 않는다. 팝업은 같은 슬롯으로 위쪽 4×2 퀵슬롯과 아래쪽 인벤토리를 구성한다.

## 필드에 버리기

- UI 밖에 놓으면 공용 수량 팝업을 연다. 선택한 컨테이너·칸에서만 차감하며 생성 실패 시 수량을 보존한다. 상점도 드래그한 칸에서만 판매한다.
- 버린 사람은 아이템이 현재 수집 반경 밖으로 나가기 전까지 해당 아이템을 수집하거나 자석으로 끌어당길 수 없다. 반경 밖으로 나갔다 돌아오면 수집 가능하다.
- `DA_GameSetting.WorldItemLifetime` 기본값은 300초, `WorldItemBlinkDuration`은 10초다. 테스트에서는 검증 액터의 수명만 짧게 설정한다.

## 화면 구성

- HP/O₂는 `BuildStatusGauge`를 공유한다. 원본 160×32의 테두리에 맞춰 왼쪽 34, 위 8, 오른쪽 7, 아래 9px를 보존한다. 레이블은 내부에서 축소·클리핑한다.
- 툴팁은 128×96 원본 모서리를 32/28px로 보존한다. 이름·종류·설명·재료·코인 가격·상태를 구분하며 아이템·기술·상점/작업대 레시피가 공통 구성요소를 사용한다.
- `ItemDataTable.DisplayName/Description`, `ShopRecipeDataTable.Description`을 추가했다. `ApplyInventoryUX.py`는 비어 있는 UI 문구와 프레임 슬라이스를 적용하고 기존 아이콘·효과·가격·재료 필드를 유지한다.
- 레시피 호버에는 재료 아이콘과 보유/필요 수량을 표시한다. 기술 툴팁은 습득 완료·선행 기술 필요·코인 부족·구매 가능 상태를 구분한다. 가격 데이터는 변경하지 않는다.
- 스킬 노드는 96→84px, 첫 줌은 0.85다. 화살표는 직교 연결 경로의 중앙에서 다음 노드를 향한다.
- 팝업·스킬 중앙에는 기존 캐릭터 데이터의 정면 대기 첫 스프라이트를 표시한다. 카메라·렌더 타깃과 새 캐릭터 아트는 사용하지 않는다.
- 미리보기 사각 배경을 제거하고 공용 구분선으로 그림과 리스트를 나눈다. 팝업의 두 줄 퀵슬롯에 긴 퀵바 이미지를 늘려 쓰지 않는다.
