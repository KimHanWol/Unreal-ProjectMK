# 팝업·HUD 표시 수정

## 확인한 원인

- 실행 중인 제작·상점의 ScrollBox 4개 모두 `animate_wheel_scrolling=False`였다. 휠 입력을 즉시 위치 변경으로 처리해 단계적으로 보였다.
- 제작 팝업을 연 상태의 Slate 180프레임 표본은 평균 13.63ms, p95 16.68ms, 50ms 초과 1회였다. 이 표본만으로 모든 성능 문제를 배제하지 않으며, 반복되는 휠 점프는 애니메이션 설정과 직접 연결된다.
- Panel은 160×120 원본의 모서리 장식보다 작은 16px에서 절단하고 있었다. InsetPanel도 8px 절단으로 모서리 일부가 중앙 스트레치 영역에 들어갔다.
- 퀵슬롯은 별도 뷰포트 레이어 10, 툴팁은 HUD 내부 캔버스였다. 내부 ZOrder 100으로는 퀵슬롯 위에 표시할 수 없었다.
- 플레이어 InventoryComponent의 `hidden_in_game=False`, `visible=True`, 빨간 shape_color를 런타임에서 확인했다.
- 미니맵은 제목을 별도 행으로 배치하고 내부 패딩과 종횡비 맞춤 여백을 추가했다. 지형을 프레임·깊이 텍스트보다 나중에 그리는 구조여서 텍스트를 겹쳐 배치할 수도 없었다.
- 개별 체력·산소 위젯의 ApplyProgressBarStyle이 공통 게이지의 채움 스타일을 단색으로 덮어쓰고 있었다.

## 공통 적용

- ScrollBox 공통 스타일에서 휠 보간 12/s, 오버스크롤 해제. 넘치는 목록에만 스크롤바를 표시한다.
- 기존 ScrollHandle의 중앙 10×10px 손잡이만 PaperSprite SourceUV (11, 11)로 분리한다. 원본에 같이 그려진 레일은 늘리지 않는다. 별도의 어두운 트랙을 사용하고 손잡이 끝 장식 2px을 9-slice로 보존한다. 원본 래스터는 변경하지 않는다.
- Panel 32px, InsetPanel 16px, Minimap 32px 모서리 안전 영역을 사용한다. 스타일 재적용 스크립트도 같은 설정을 따른다.
- UMKMenuBase가 제목을 닫기 버튼 왼쪽 헤더에 한 번만 만든다. 제작·상점·기술 트리 내부의 중복 제목판을 제거한다.
- 공용 툴팁은 독립 뷰포트 레이어 100에서 표시한다. 수량 모달 200보다 아래, HUD·퀵슬롯보다 위이며 입력을 가리지 않는다.
- 인벤토리 구체는 BeginPlay에서도 숨김을 적용해 BP의 이전 설정을 덮어쓴다. 충돌과 수집 기능은 유지한다.
- 게이지는 기존 HealthFill/OxygenFill의 명암과 색을 사용한다. HP/O2와 깊이 숫자는 공통 HUDMetric 역할의 Roboto Bold Condensed, 자간·얇은 윤곽을 적용한다.
- 미니맵은 지형 전용 하위 위젯에서 프레임 안쪽 6px까지 채운다. 프레임과 깊이 숫자를 그 위에 표시하고 지도 내용은 종횡비를 유지하며 가장자리에서 자른다.

## 캐릭터 패시브

SkillDataTable의 `AcquisitionType`은 `SkillTree`와 `CharacterPassive`를 구분한다. 광부 집안, 넘치는 열정, 가벼운 발걸음, 큰손 4개 행을 CharacterPassive로 설정한다. 캐릭터 패시브는 구매와 스킬트리 노드 생성에서 제외하며 이전 구매 목록을 로드할 때도 구매 기술로 적용하지 않는다. 캐릭터 선택에 따른 고유 패시브 지급은 별도 캐릭터 구현에서 처리한다.
