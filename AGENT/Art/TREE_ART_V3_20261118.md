# 나무 재질 정리 — 2026-11-18

기본 제공 image_gen을 사용했다. `COMMON_PIXEL_ART_PROMPT.md`, 기존 HouseA·Lumberyard 목재와 금속의 색·픽셀 밀도를 기준으로 했다. 줄기는 회색의 큰 수피 조각 대신 따뜻한 갈색 세로 나뭇결, 잎은 대비를 낮춘 올리브색 덩어리와 작은 내부 투명 틈으로 구성한다. 모든 최종 타일은 32×32, 월드에서는 2 pixels/unit로 사용하고 노출 외곽은 기존 지형 마스크를 재사용한다. 잎 타일 외곽 여백을 없애 연결된 칸 사이에 테두리가 생기지 않게 한다.

원본과 최종 PNG: `Content/Asset/TreeArtV3/Source/`. 준비 스크립트: `AGENT/Scripts/PrepareTreeArtV3.ps1`; 임포트: `AGENT/Scripts/ApplyTreeArtV3.py`.
