# ArtV2 및 픽셀 밀도 적용

2026-10-20. 디자인은 교체 가능하게 분리하고, 요소 크기에 맞는 원본 해상도를 게임에 적용했다. 캐릭터·몬스터 디자인과 애니메이션은 기존 자산을 유지한다.

## 크기 기준

월드 그래픽의 기본값은 2 pixels per Unreal unit이다. 원본 픽셀 하나가 월드 0.5 단위에 대응한다. 모든 파일을 32×32로 맞추는 기준은 사용하지 않는다.

| 요소 | 원본 해상도 | 게임 내 크기 | 기준 |
|---|---|---|---|
| 블록·광맥 | 32×32 | 16×16 | 블록 한 칸 |
| 파괴 효과 | 64×64 | 32×32 캔버스 | 두 칸 범위, 투명 여백 포함 |
| 기본 발파 효과 | 96×96 | 48×48 캔버스 | 반경 1 폭약의 세 칸 범위 |
| 지상·지하 배경 | 512×512 | 256×256 | 한 타일당 블록 16칸 |
| 드릴 접촉 효과 | 24×24 | 폭 11.2 | 기존 0.7칸 연출 크기 유지 |
| 획득 효과 | 20×20 | 폭 9.6 | 기존 0.6칸 연출 크기 유지 |

작은 접촉·획득 효과는 연출 배율로 인해 픽셀당 월드 크기가 약 0.467/0.48이다. UI는 화면 DPI와 패널의 nine-slice 기준을 따르며, 기존 캐릭터·드롭 아이템의 별도 배율을 모두 재설정한 작업은 아니다. 카메라 위치·화면 배율까지 정수로 고정하는 완전한 픽셀 퍼펙트 렌더링을 의미하지 않는다.

공용 효과 생성 함수는 첫 프레임의 해상도와 PixelsPerUnrealUnit을 사용해 목표 블록 너비를 계산한다. 이후 효과 원본 해상도를 바꿔도 지정된 연출 범위를 유지한다. 큰 이미지에는 작은 PNG 확대본 대신 원본 아틀라스의 세부 정보를 사용한다.

## 적용 자산

상하좌우 노출 상태에 따른 외곽 처리는 [TERRAIN_EDGES.md](TERRAIN_EDGES.md)를 따른다. 중앙 텍스처는 유지하고 지형 가장자리만 다듬는다.

- `/Game/Asset/ArtV2/Terrain`: 흙·잔디·돌·모래·얼음 5종을 BlockDataTable에 연결했다. 마그마는 예비 자산이며 기존 테이블에 없는 행을 추가하지 않았다.
- `/Game/Asset/ArtV2/Ores`: 8종의 광맥을 ItemDataTable의 BlockOverlaySprite에 연결했다. 인벤토리용 ItemIcon은 별도로 유지한다.
- `/Game/Asset/ArtV2/Backgrounds`: 새 512×512 지하 배경을 Main 레벨에 연결했다.
- 원본과 추출 PNG는 `Content/Asset/ArtV2/Source`, 생성 지시는 [ART_V2_PROMPTS.md](ART_V2_PROMPTS.md)에 보관한다.
- ArtV1의 기존 지형과 광맥은 원본 보관용으로 유지한다. 새 지형은 사각 외곽선과 광물의 광택을 줄이는 방향으로 제작했으며 미술 조정은 이후 교체 가능하다.

## 배경 반복과 경계

지상 산 디자인은 유지하고 고해상도 원본에서 512×512로 재추출했다. 지하 배경은 작은 128×128 무늬의 확대 대신 더 넓은 영역의 새로운 무늬를 생성했다. 같은 픽셀 밀도에서 반복 타일의 너비가 블록 4칸에서 16칸으로 늘었다.

배경 타일은 좌우로 번갈아 반전한다. 지하 배경은 위아래로도 번갈아 반전한다. 이웃한 타일이 같은 끝 픽셀을 공유하도록 구성했고, Texture Address X/Y를 Clamp로 설정해 UV 끝에서 반대편 픽셀을 읽지 않게 했다. Nearest 필터와 NoMipmaps를 사용한다. 반전 반복이므로 대칭 무늬가 남을 수 있으며, 무한 비반복 배경은 아니다.

## 검증

- Development Editor 빌드 성공. 마지막 C++ 수정 이후 빌드된 상태에서 PIE 실행을 확인했다.
- [파일 검증](../../output/art-v1/validation-report.json): 130개 PNG의 크기·알파, 보관 원본 16개의 픽셀 동일성, DataTable의 그래픽 외 필드 동일성 확인.
- [에디터 검증](../../output/art-v1/editor-validation-report.json): Texture 130개, Sprite 130개, 4프레임 Flipbook 5개, 런타임 스타일·미니맵 1개·퀵슬롯 8개, 오류 없음.
- [배경 크기 검증](../../output/art-v1/scale-after.json): 두 배경 모두 512px/PPU 2, 타일 너비 256, 모든 반전 플래그 확인.
- [폭약 실행 검증](../../output/art-v2/effect-runtime-report.json): 실제 폭약 사용으로 96px 폭발 효과 생성, 액터 배율 1, 월드 너비 48, 픽셀당 0.5, 충돌 없음 확인.
- 테스트 아이템 사용은 저장을 차단하는 Playtest 세션에서 수행했다.

## 재적용

ArtV1 기본 적용 후 `PrepareArtV2.cjs` → Unreal에서 `ApplyArtV2.py` 순서로 실행한다. Main 레벨을 열고 PIE를 종료한 상태여야 한다. 기존 Texture의 PNG를 변경하면 명시적으로 Reimport해야 한다. 적용 결과는 [application-report.json](../../output/art-v2/application-report.json)에 기록한다.
