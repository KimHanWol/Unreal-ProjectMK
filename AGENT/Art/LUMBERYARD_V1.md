# 벌목장·연결 수관·가로등 V1

`COMMON_PIXEL_ART_PROMPT.md`와 기존 HouseA·VillageNotice·TreeLeaves·LanternPost 원본을 참고해 내장 imagegen으로 생성했다. 원본과 게임용 PNG·공통 수관 셀 목록은 `Content/Asset/LumberyardV1/Source`에 보존한다. 캐릭터 자원은 추가하지 않았다.

| 자원 | 네이티브 캔버스 | 적용 |
|---|---|---|
| Canopy | 160×96 | 연속된 수관 원본 한 장 |
| TreeLeaves_0_0 … TreeLeaves_4_2 | 각32×32 영역 | 수관 텍스처의 고정 UV 영역15개. 칸별 여백 정리·확대 없음 |
| Lumberyard | 192×128 | 통나무·판재·톱·도끼·작업대를 갖춘 벌목 오두막 |
| PlantingBed | 192×32 | 나무가 자라는 목재 화단과 낮은 뒤 울타리 |
| LanternPost | 48×112 | 높이와 폭을 더 확보한 목재 가로등 |

모두 PPU2·Nearest·NoMipmaps·hard alpha다. 가로등은 액터 배율1로 사용해 새 원본의 픽셀 밀도를 유지한다. 수관 내부를 하나의 그림으로 생성하고 32픽셀씩 원래 좌표대로 나눴으므로 이웃한 잎의 무늬와 불투명 영역이 그대로 이어진다. 바깥쪽 윤곽은 불규칙하며 채굴·붕괴는 각 칸에서 처리한다.

## 재적용

1. `PrepareLumberyard.ps1`에 CanopySource와 PropsSource를 전달한다. 원본은 각각 canopy-original.png·props-original.png다.
2. `ApplyLumberyard.py`로 스프라이트·잎 블록 행·스타일·배치 설정을 적용한다.

기존 마을 자원부터 다시 적용할 때는 TownArtV2 → MineExpansion → Lumberyard 순서로 실행한다.

## 생성 지시

수관: 첫 참고 잎 그림의 올리브색·질감과 주택의 명확한 픽셀 묶음을 따른다. 160×96의 넓고 불규칙한 단일 수관을 만들고 가상의32픽셀 내부 경계에는 틈이 없게 한다. 중심은 잎으로 채우고 바깥만 투명하게 하며 하단 중앙은 별도 줄기와 닿는다. 작은 잎 덩어리를 반복하는 도안·트렁크·배경·문자·광택·블러·그라데이션은 포함하지 않는다.

시설 시트: 기존 낡은 목재·철물·절제된 황동·따뜻한 작업등을 사용한다. 위 왼쪽은 통나무를 다듬는 오두막, 위 오른쪽은 버팀대와 따뜻한 등불이 있는 큰 목재 가로등, 아래는 흙과 낮은 뒤 울타리가 있는 긴 목재 화단이다. 원본 간 충분한 여백과 투명 배경을 두고 인물·문자는 넣지 않는다.
