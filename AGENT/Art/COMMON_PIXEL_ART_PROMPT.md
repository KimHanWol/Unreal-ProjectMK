# Common pixel-art prompt

Use this shared prompt with an asset-specific prompt. Terrain is the palette reference. For non-emissive mineral overlays, keep muted material colors and restrained highlights. Preserve approved geometry when recoloring.

```text
Create cohesive 2D pixel-art game assets on the native logical pixel grid specified for each asset. Match pixel density across objects, not canvas dimensions: one 16-world-unit block uses 32x32 pixels at 2 pixels per Unreal unit; larger objects and backgrounds use proportionally larger source canvases with more detail at the same pixel scale. Do not enlarge a small sprite to imitate a higher-resolution source. Examples: block 32x32, block-break canvas 64x64, three-block-wide explosion 96x96, background tile 512x512. UI follows its own screen-space scale and nine-slice margins. Use crisp intentional pixel clusters, hard alpha, no antialiasing, blur, gradients, bloom or subpixel details. Transparent PNG background where not occupied by the asset.
TERRAIN AND BACKGROUNDS:
Avoid square outlines, bevels, perimeter shadows and frame-like edge shading. Carry restrained irregular material patterns through tile boundaries. Mineral overlays are matte angular embedded veins, with no polished bead-like highlights. Make large background sources varied across a wide area instead of repeating a small motif inside the source. Keep background contrast below foreground terrain contrast.
COLOR STYLE — shared across terrain, minerals and props:
Use the supplied terrain tiles as the primary color and contrast reference. Favor muted earthy midtones and softly tinted neutral shadows. Keep each material to 3-5 stepped shades with modest value separation. Highlights are small and subdued, tinted by the material; avoid pure white specular spots and pure black outline halos. Use restrained saturation: no electric blue, neon cyan, emerald neon green, saturated magenta, or vivid orange metal. Reserve strongly saturated emissive colors for lava or explicitly luminous effects; ordinary minerals never emit light. Mineral overlays must look like part of the terrain surface, not bright UI icons. Separate material types through hue families and shapes rather than large brightness or saturation jumps. Keep modest consistent upper-left lighting, low-relief shading, balanced texture density and soft-looking but sharply pixelated edges. Preserve readability on warm dirt, cyan ice, dark basalt and neutral gray stone without adding bright outlines. No text, labels, watermark, presentation background or decorative frame.
```
