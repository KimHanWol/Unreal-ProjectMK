# 마을 확장 아트 V1

기존 `COMMON_PIXEL_ART_PROMPT.md`, `TOWN_ART_V2.md` 및 실제 VillageNotice·HouseA·Shop 원본을 기준으로 내장 imagegen을 사용했다. 캐릭터는 포함하지 않는다.

| 자원 | 네이티브 크기 | 적용 |
|---|---|---|
| Shop | 192×168 | 보급소 월드 스프라이트, 6칸 너비, 2px/월드 단위 |
| IndustrialBackdrop | 512×160 | 승강기·철도 작업장 뒤편의 낮은 대비 창고·권양기·차륜 작업장 |
| TreeTrunk / TreeLeaves | 각32×32 | 기존 채굴·붕괴 시스템으로 조립하는 벌목 나무 |
| Wood | 32×32 | 목재 드랍·인벤토리·제작 재료 아이콘 |

원본과 최종 PNG는 `Content/Asset/MineExpansionV1/Source`에 보존한다. 원본의 투명 여백을 정리하고 비율을 유지해 Nearest로 네이티브 크기에 넣었다. hard alpha, Nearest, NoMipmaps, MaskedUnlit, PPU2를 적용한다. 나무의 개별 조각도 기존 블록과 같은 픽셀 밀도를 사용한다.

재적용: `PrepareMineExpansion.ps1`에 원본 3개를 전달한 뒤 `ApplyMineExpansion.py`를 실행한다. 후자는 목재 데이터·제작 재료와 실제 DrillCrawler 행을 사용하는 퇴치 의뢰도 등록한다. 주택·벽보·상자·열차 원본은 보존한다.

## 생성 프롬프트

- Shop: VillageNotice와 HouseA를 스타일 기준, 기존 Shop을 기능 기준으로 삼아 전면 직교 시점의 광산 소매점을 제작. 회색 슬레이트 지붕, 낡은 목재, 청록·크림색 차양, 판매 창구와 광산 용품 선반·작은 작업등. 인물·문자 없음. 재질당 3~5단계의 낮은 채도, 명확한 픽셀 클러스터, 투명 배경, 평평한 하단 접지선.
- IndustrialBackdrop: 같은 풍의 낮은 대비 배경 그룹. 권양기 창고·작은 광산 적재용 갠트리·레일 적치·차륜과 차축이 있는 개방 작업장. 전경 랜드마크보다 작은 건물들의 조합, 동일한 바닥선, 512×160 네이티브 설계. 인물·문자·지면·풍경 없음.
- Tree tileset: 32×32 셀 세 개의 가로 시트. 수직 연결되는 거친 회갈색 줄기, 올리브색의 불규칙한 잎 덩어리, 묶인 짧은 통나무 아이콘. 투명 셀 간격, 테두리·광택·그라데이션·블러 없음. 전체 나무 그림 대신 조립 가능한 블록 재료.

## 배치 보정

배경 주택 하단은 표시 범위의 낮은 지면을 기준으로2월드 단위 묻어 띄워 보이는 틈을 없앴다. 각 배경은 캐릭터의 상대 X에0.035배 역방향 시차를 주고 최대12월드 단위로 제한한다. 산업 배경은 전경과 구분하도록 기존 TranslucentUnlit 재질과 낮은 대비·알파0.62를 적용했다. 기존 가로등은 접지 하단을 유지하며15% 확대했다. 나무는 줄기3칸 위에5칸 폭의 수관을 조립하고 중앙 잎도 채워 긴 기둥처럼 보이지 않게 했다.
